# Technibel IR capture log — 2026-08-15

This is a chronological laboratory log for the ESPHome Technibel reverse-engineering work.
It deliberately keeps uncertain observations separate from decoded control frames.

## Recording rules

- Record local time (Europe/Zurich), source (`remote` or `xiao`), and the state shown on the remote before pressing a button.
- Keep every packet class: short Pronto packets, non-standard symbol counts, and the canonical `n_sym=99` frame.
- Preserve the raw Pronto line before decoding. A decoded six-byte frame is an interpretation, not a replacement for the raw capture.
- Mark the physical result separately: no response, beep, fan movement, LED change, or unknown.
